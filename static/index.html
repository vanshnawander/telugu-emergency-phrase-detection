          Distance Metrics & Word Error Rate

          Our system uses advanced distance metrics instead of direct string matching to improve accuracy and reduce false positives/negatives in emergency phrase detection.

          Levenshtein Distance

          Measures the minimum number of single-character edits required to change one word into another.

          Formula: Distance ≤ min(3, ceil(max_len × 0.25))
          Example: "డాక్టర్" vs "డాక్టర్‌ను" → Distance: 2 (Match!)

          Windowed Matching

          Sliding window approach to handle partial ASR output and word order variations.

          Window Size: Phrase length ± 1 word
          Example: "హెల్ప్ చేయండి" detected in "దయచేసి హెల్ప్ చేయండి త్వరగా"

          Word Error Rate (WER)

          Comprehensive metric combining substitutions, deletions, and insertions.

          WER = (S + D + I) / N
          Where: S=Substitutions, D=Deletions, I=Insertions, N=Reference words
          Example: Reference: "అంబులెన్స్ పిలవండి"
          Hypothesis: "అంబులెన్స్ పిలవండి రా" → WER: 25%

          Approach Comparison

          Exact String Match

          Method: Direct substring matching after text normalization.

          Limitations: Fails with minor spelling errors, word variations, or ASR transcription errors.

          Use Case: Simple applications with high-quality audio input.

          Distance Metrics Approach

          Method: Combines Levenshtein distance, windowed matching, and normalization.

          Advantages: Handles transcription errors, word variations, and partial matches.

          Use Case: Real-world emergency systems where accuracy is critical.
