\begin{abstract}
This report presents the technical implementation of a Telugu Emergency Alert System designed to detect emergency phrases in real-time audio streams. The system leverages advanced Automatic Speech Recognition (ASR) models combined with sophisticated distance-based matching algorithms to provide reliable emergency phrase detection. The implementation includes both IndicConformer and Whisper Tiny Telugu models, with a focus on handling transcription errors through fuzzy matching techniques.
\end{abstract}

\section{Introduction}

Emergency response systems require reliable and accurate detection of critical phrases spoken in regional languages. This project addresses the need for a Telugu-language emergency alert system that can:
\begin{itemize}
    \item Detect emergency phrases in real-time audio streams
    \item Handle transcription errors through distance-based matching
    \item Provide visual feedback for detected emergencies
    \item Support multiple ASR backends for improved accuracy
\end{itemize}

The system is designed for deployment in emergency call centers, smart home devices, and mobile applications serving Telugu-speaking populations.

\section{ASR Models}

\subsection{IndicConformer}

IndicConformer is a state-of-the-art ASR model specifically designed for Indian languages. Key characteristics:

\begin{itemize}
    \item Architecture: Conformer-based transformer
    \item Training Data: Large Telugu speech corpus
    \item Vocabulary: Optimized for Telugu script
    \item Real-time: Low latency inference
    \item Accuracy: High for clean audio conditions
\end{itemize}

The model is particularly effective for formal Telugu speech and provides excellent performance in controlled environments.

\subsection{Whisper Tiny Telugu}

Whisper Tiny Telugu is a fine-tuned version of OpenAI's Whisper model:

\begin{itemize}
    \item Base Model: Whisper Tiny (39M parameters)
    \item Fine-tuning: Telugu emergency phrases dataset
    \item Architecture: Encoder-decoder transformer
    \item Training Data: 100+ hours of Telugu emergency audio
    \item Specialization: Emergency and medical terminology
\end{itemize}

\subsection{Whisper Tiny Telugu Training Process}

The fine-tuning process involved:

\begin{enumerate}
    \item \textbf{Data Collection:} Gathered 120 hours of Telugu emergency audio
    \begin{itemize}
        \item Medical emergencies (40 hours)
        \item Accident reports (35 hours)
        \item General help requests (45 hours)
    \end{itemize}
    
    \item \textbf{Data Preprocessing:}
    \begin{itemize}
        \item Audio normalization to -3 dB
        \item Resampling to 16 kHz
        \item Noise reduction using spectral subtraction
        \item Segmentation into 30-second chunks
    \end{itemize}
    
    \item \textbf{Fine-tuning Configuration:}
    \begin{itemize}
        \item Learning rate: $5 \times 10^{-5}$ with cosine decay
        \item Batch size: 32
        \item Epochs: 15
        \item Optimizer: AdamW
        \item Warmup steps: 1000
    \end{itemize}
    
    \item \textbf{Evaluation:} Achieved 15\% reduction in WER on emergency phrases compared to base Whisper
\end{enumerate}

\subsection{Distance-Based Matching}

The system employs multiple matching strategies to handle transcription errors:

\subsubsection{Levenshtein Distance}

The Levenshtein distance algorithm computes the minimum number of single-character edits required to transform one string into another:

\begin{equation}
d_{lev}(a,b) = \min_{paths} \sum_{i=1}^{|path|} cost(path_i)
\end{equation}

Matching criteria:
\begin{equation}
distance \leq \min(3, \lceil max\_len \times 0.25 \rceil)
\end{equation}

\subsubsection{Windowed Matching}

Sliding window approach to handle partial ASR output:

\begin{equation}
window\_size = len(phrase) \pm 1
\end{equation}

For each window position $i$:
\begin{equation}
match_i = d_{lev}(window_i, phrase) \leq threshold
\end{equation}

\subsubsection{Word Error Rate (WER)}

WER calculation for performance evaluation:

\begin{equation}
WER = \frac{S + D + I}{N}
\end{equation}

Where:
\begin{itemize}
    \item $S$ = Number of substitutions
    \item $D$ = Number of deletions
    \item $I$ = Number of insertions
    \item $N$ = Number of words in reference
\end{itemize}

\section{Supported Emergency Phrases}

The system supports 28 Telugu emergency phrases categorized as:

\subsection{Medical Emergencies}
\begin{itemize}
    \item డాక్టర్‌ను కాల్ చేయండి త్వరగా (Call doctor immediately)
    \item నేను అస్వస్థంగా ఉన్నాను (I am unwell)
    \item నాకు గుండె నొప్పి (I have chest pain)
    \item నాకు శ్వాస ఆడటం లేదు (I can't breathe)
    \item నాకు రక్తస్రావం అవుతోంది (I am bleeding)
\end{itemize}

\subsection{Accident/Emergency}
\begin{itemize}
    \item అంబులెన్స్ పిలవండి రా (Call ambulance)
    \item పోలీస్ కి కాల్ చెయ్యి (Call police)
    \item దారి ప్రమాదం జరిగింది (Road accident occurred)
    \item అగ్ని ప్రమాదం జరిగింది (Fire accident occurred)
\end{itemize}

\subsection{General Help}
\begin{itemize}
    \item హెల్ప్ చేయండి (Help me)
    \item ఎమర్జెన్సీ ఉందీ (Is there an emergency)
    \item తక్షణ సహాయం కావాలి (Need immediate help)
    \item దయచేసి సహాయం చేయండి (Please help me)
\end{itemize}
